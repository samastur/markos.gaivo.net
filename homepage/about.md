# About me

After an embarrassing start writing backup software, I have been working in
technology for almost 20 years in a variety of roles before settling down as a
full-stack web developer with a penchant for front-end development.

I now work as an independent software consultant specializing in web solutions
for low-resource environments which is another way of saying I use web
technologies to build websites and mobile applications that work well
everywhere.

You can read more about what I do (and did) at
[LinkedIn](http://si.linkedin.com/in/markosamastur "Hire me") or
[contact me](mailto:markos@gaivo.net) for further information.

I live in
[Ljubljana, Slovenia](http://maps.google.com/maps?q=ljubljana+google+maps&ll=46.052386,14.507103&spn=0.091971,0.167198&t=h&z=13 "Ljubljana on Google maps"),
have a wonderful wife, hate making phone calls and don't have a pet. In my
spare time I like to read books, travel, ski and design social software for
introverts.
